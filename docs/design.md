# EduPredict Design System

## 1. UI/UX Guidelines

- Keep the interface clean and intuitive
- Use a consistent layout across Admin, Teacher, and Student roles
- Prioritize clarity and accessibility
- Keep navigation simple and predictable
- Design for mobile-first responsiveness
- Reuse common components and patterns

## 2. Color and Theme

### Primary Colors
- Navy / Deep Blue: primary branding and headers
- White / Off-white: major surfaces and backgrounds

### Secondary Colors
- Soft Gray: cards and section backgrounds
- Slate: secondary content and borders

### Accent Colors
- Teal or Green: success states and positive metrics
- Amber: warnings and alerts
- Red: error states and rejected documents

### Text Colors
- Dark text for readable content
- Muted gray for helper text
- High-contrast labels for accessibility

### Status Colors
- Success: green
- Warning: amber
- Error: red
- Info: blue

### Theme Support
- Light theme as default
- Optional dark mode support later if needed

## 3. Fonts and Typography

### Primary Font Family
- Inter, Segoe UI, or similar modern sans-serif font

### Type Scale
- H1: 32px, bold
- H2: 24px, semibold
- H3: 20px, semibold
- Body: 16px, regular
- Small text: 13px, medium

### Line Heights
- Headings: 1.2 to 1.4
- Body text: 1.5 to 1.7

## 4. UI Memory Preferences

The application may remember the following user preferences later:
- Light or dark theme
- Sidebar expansion/collapse state
- Language preference
- Layout density settings
- Notification preferences

## 5. Layout Principles

- Use cards for dashboards and summaries
- Provide clear hierarchy and spacing
- Keep forms readable and compact
- Use empty states and informative messages where needed
- Ensure all actions are visible and understandable
